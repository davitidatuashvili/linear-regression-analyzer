Linear Regression Analyzer — გაშვების ინსტრუქცია (Windows PowerShell)

1. გახსენით პროექტის საქაღალდე PyCharm-ში ან PowerShell-ში.
2. შექმენით ვირტუალური გარემო:
   py -3.12 -m venv .venv
3. გააქტიურეთ:
   .\.venv\Scripts\Activate.ps1
4. დააყენეთ ბიბლიოთეკები:
   python -m pip install -r requirements.txt
5. გაუშვით:
   uvicorn app.main:app --reload
6. ბრაუზერში გახსენით:
   http://127.0.0.1:8000

გამოყენება:
- ატვირთეთ CSV.
- მონიშნეთ კატეგორიული სვეტები.
- აირჩიეთ დამოკიდებული (y) და დამოუკიდებელი (X) ცვლადები.
- მიუთითეთ test_size და გაუშვით LinearRegression.

შენიშვნები:
- გამოტოვებული მნიშვნელობები წინასწარ უნდა გასუფთავდეს.
- მიზნობრივი ცვლადი უნდა იყოს რიცხვითი.
- ეს არის ერთპროცესიანი სასწავლო დემო; ფაილები დროებით ინახება RAM-ში.
- კატეგორიები გარდაიქმნება pd.get_dummies(drop_first=True, dtype=int)-ით.
- გაყოფა ხდება გარდაქმნის შემდეგ — სასწავლო სიმარტივისთვის; რეალურ ML პროექტში encoding უნდა ისწავლებოდეს მხოლოდ train ნაწილზე.
